# Time to Cook

작은 인천 식당에서 첫 닭강정을 튀겨 보세요. 손님의 주문을 받고, 바삭한 순간을 놓치지 않고, 함께 식탁을 정리하며 나만의 식당을 키우는 실시간 요리 경영 게임입니다.

혼자 모든 일을 배우거나 친구와 온라인 2인 협동으로 역할을 나눌 수 있습니다. 한 사람은 주방을 지키고, 다른 사람은 차를 몰아 동네 마트에 부족한 재료를 사러 다녀오세요. 재료를 사는 동안에도 영업은 계속됩니다.

- 직접 칼질하고 튀기고 서빙하는 닭강정 주방
- 홀과 포장 고객, 식탁 청소, 09시부터 21시까지의 영업과 마감
- 7직종 직원과 휴가·만족도·휴게 시설 관리
- 5종 차량과 직접 운전하는 긴급 장보기
- 연구·메뉴·가격·광고·대출·인테리어를 통한 성장
- 한국과 일본 16개 도시의 프랜차이즈 경영
- 따뜻한 픽셀 아트와 한국어 인터페이스

온라인 협동은 IP 직접 연결 방식입니다. 같은 LAN 또는 UDP 7777 포트포워딩이 필요할 수 있습니다. 자동 매치메이킹과 Steam 친구 초대 연동은 제공되지 않습니다.

이 문서는 상점 설명 초안입니다. 실제 제공 기능, 아트와 AI 생성 콘텐츠 고지, 지원 환경, 출시 준비 상태를 검토한 뒤 제출하세요.
