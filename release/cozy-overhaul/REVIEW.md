# 3/4 비주얼 개편 검토

기존 화면은 작은 가구를 일정 간격으로 늘어놓고 큰 상하단 HUD를 덧씌운 구성이었습니다. 새 화면은 앞면이 보이는 키 큰 수납장, 연결된 조리대와 작업 섬, 두 칸 식탁, 도시별 창문·낮은 칸막이·좌석으로 공간을 구성합니다. 바닥 무늬는 64px 재료를 사용하고 창빛, 접지 그림자, 조리 증기를 더했습니다.

캐릭터는 32×48 프레임과 실제로 달라지는 팔·다리 동작을 사용합니다. 레스토랑의 바닥/건축/가구/인물 레이어를 분리하고 발 기준 Y 정렬을 적용했습니다. 하단 긴 튜토리얼은 도움말로 옮기고, 경영 메뉴는 그림이 있는 카드로 정리했습니다. 거리 건물, 차량 크기, 마트의 품목별 진열대도 교체했습니다.

## 범위와 호환성

경제·연구·네트워크·소유권·저장 형식은 유지했습니다. 새 배치는 새 게임과 새로 개설한 매장에 적용됩니다. 기존 매장은 저장된 위치와 한 칸 충돌 크기를 유지하고 새 그림을 맞춰 표시합니다. 식탁은 가로/세로 전용 그림으로 방향을 바꾸며, 가구 전체를 90도 돌려 시점을 무너뜨리지 않습니다.

자동 검사 결과는 동작 회귀를 확인하는 자료이며, 미술의 상용 품질을 보증하는 지표가 아닙니다. 이번 실행의 배치·캡처 결과는 `results.json`, Windows 빌드와 실행 확인은 `build.json`을 참고하세요. 이전 `visual-refresh` 폴더는 이전 버전의 증거입니다.
