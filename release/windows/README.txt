Time to Cook - Windows review build

Run TimeToCook.exe with TimeToCook.pck beside it.

WASD: move/drive. J: interact. K: work/clean. Q: drop.
1-9,0 or wheel: inventory. Tab: recipe. L: ability. M: management.
B: construction, or grocery shopping inside the grocery store.

New game -> buy chicken, flour and containers -> Ready.
Use the in-game Korean tutorial and help from Management / Records.
Co-op uses direct IP over UDP 7777; host owns the save.

Saves: %APPDATA%/Godot/app_userdata/Time to Cook/franchise_v2/

This is a human-review build. Long-term balance, WAN behavior and
all supported PCs have not been certified. Nothing was uploaded to Steam.
See the repository release notes for known simplifications.
